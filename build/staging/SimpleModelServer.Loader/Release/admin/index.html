🔐 Network & Security

Configure network binding, trusted networks, and API key authentication.

⚠️ Requires Restart
global.routerHost
Host the router binds to. Use * for all interfaces (requires admin).
✓ Hot Reload
global.trustedNetworks
CIDR notation or dotted-quad (trailing zeros imply mask). Localhost always trusted.
✓ Hot Reload
global.trustedApiKeys
API keys for Bearer token authentication. Never exposed in GET requests.
